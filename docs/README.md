## The short version

Upload the zip. Create a `main-menu` and a `footer` menu. Pick a collection for
the home page Product grid. Add a hero image. That's a working store.

Then open **Theme settings**, try the three theme styles, and set the accent
colour to yours — the whole palette regenerates from it.
